A deadpan one-star review of the Sun — an everyday essential that shows up uninvited every morning, offers no snooze button, and burns your neck. One star. Would not recommend. Will be back tomorrow.

> One star for the Sun. Shows up uninvited every morning, no snooze button, no customer service, burns my neck. Would not recommend. Will be back tomorrow.

`main.py` writes exactly that one line (153 characters, no trailing newline) to `/output/entry.txt`. Standard library only — run it with `python3 main.py` (or set `MAKEFUN_OUTPUT_DIR` to choose the output folder).
